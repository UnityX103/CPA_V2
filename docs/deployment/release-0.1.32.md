# CPA_V2 0.1.32

- 使用 GitHub Actions 完成前端、服务端和 macOS / Windows 原生测试，以及三平台安装包构建与更新签名。
- CNB 每 15 分钟自动同步 GitHub 已公开的最新版，提供大陆下载镜像。GitHub 发布不再依赖 CNB 同步成功。
- 镜像验证安装包签名、资源哈希和扩展索引，复用未变化的大文件。CNB 匿名读取 GitHub，并只使用自身临时凭据写入镜像。
- 本版没有修改桌宠功能；视频编辑和蟑螂模块继续沿用上一版已验证的扩展版本。

macOS 安装包仍采用 ad-hoc 签名，本版没有新增 Apple Developer ID 签名或公证。
