# CPA_V2 0.2.0

- 优化番茄钟的专注、休息、暂停与待开始状态，沿用原有字体、配色风格与功能图标。待开始展示轮次和专注/休息时长，暂停提供清晰的恢复入口。
- 钟面悬停显示圆形分区的暂停与跳过按钮，窗口更紧凑，摄像头、设置、置顶图标固定排列。
- 设置支持修改循环轮次（默认 4 次）和自适应换行。说明收纳为问号提示，隐藏联机设置入口但保留相关实现。
- 视频编辑扩展改为按需校验，启动番茄钟不再扫描大型运行时和模型；打开编辑器时后台校验，避免阻塞界面。
- 更新检查优先获取 GitHub 最新版本，失败时查询 CNB；下载优先使用 CNB 对应版本，失败时回退 GitHub 同版本。

通过 GitHub Actions 构建 macOS ARM64、macOS Intel 和 Windows x64 安装包。视频编辑及蟑螂扩展包沿用已有已验证版本。

macOS 安装包采用 ad-hoc 签名，尚未配置 Apple Developer ID 签名和公证。
