# CPA_V2 0.2.1

- 启动后自动检查新版本，先展示更新预览，由用户选择后才下载和安装。
- 更新内容按版本分组，包含当前版本到最新版之间的正式版说明，支持展开、收起与滚动查看。历史说明暂不可用时明确提示，并显示最新版本说明。
- 可选择“更新”“跳过此版本”或“稍后提醒（1 小时）”。跳过和提醒时间持久化；设置中的“立即检查”可以重新查看已跳过的版本。
- 新增左右靠边停靠：细进度条、块模式与完整番茄钟按交互切换，保存停靠位置并在下次启动时恢复。
- 优化多屏边界、拖拽、暂停恢复与状态切换提醒；固定过渡圆角，消除尺寸变化期间的文字闪烁。
- 块模式内的提示缩小字号和内边距、自动换行，避免内容溢出。

通过 GitHub Actions 构建 macOS ARM64、macOS Intel 和 Windows x64 安装包。现有扩展包保持不变。

macOS 安装包采用 ad-hoc 签名，尚未配置 Apple Developer ID 签名和公证。
