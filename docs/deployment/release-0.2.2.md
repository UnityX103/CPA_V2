# CPA_V2 0.2.2

- 修复升级后恢复旧缩放设置时，停靠窗口可能仍按 1 倍尺寸初始化的问题。现在等待设置加载，并将当前缩放同步给停靠窗口。
- 停靠窗口尺寸向上取整，禁用停靠区域的滚动条，避免非整数缩放时界面被截断或被 Windows 滚动条挤占。
- 将窗口缩放调整移到后台，避免主线程等待停靠锁时与原生窗口操作互相阻塞。
- 进入或恢复专注后，自动展开的块在持续 5 秒未获得焦点时收回细进度条；获得焦点则取消计时，沿用失焦收回行为。
- 休息和暂停不应用定时收回规则，开始拖拽或再次切换状态会取消旧计时，避免误收回。

通过 GitHub Actions 构建 macOS ARM64、macOS Intel 和 Windows x64 安装包。现有扩展包保持不变。

macOS 安装包采用 ad-hoc 签名，尚未配置 Apple Developer ID 签名和公证。
